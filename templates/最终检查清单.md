# 最终检查清单

## 材料与数据

- [ ] 已清点全部相关材料并识别重复版本
- [ ] 无法读取和来源不明的材料已记录
- [ ] 每问预处理段与实际代码一致
- [ ] 样本量、分组数、字段和单位已复核

## 模型与结果

- [ ] 每问先回答题目，再解释模型
- [ ] 变量关系使用专业统计术语并有指标支持
- [ ] 非单调关系和例外组合已单独说明
- [ ] 复杂模型相对简单基线有明确收益
- [ ] 近完美拟合已检查错误、泄漏和过拟合
- [ ] 优化域、约束、步长或终止条件已记录
- [ ] 验证形成了支持主要结论的证据链

## 数字一致性

- [ ] 代码、Excel、图、正文、摘要和附录数值一致
- [ ] 单位、正负号、百分比尺度和约束一致
- [ ] 结果表默认保留四位小数

## 论文

- [ ] 摘要每问突出 3 至 4 个重点并直接回答问题
- [ ] 前置内容和每问正文符合页数预算
- [ ] 每段加粗不超过 3 至 5 个关键词
- [ ] 无明显模板化、口语化或防御性表述
- [ ] 实际应用与价值表述简洁且未夸大

## 图表与表格

- [ ] Excel 文件、工作表和字段使用中文名称
- [ ] 论文图片为中文文件名且不重复放置总标题
- [ ] 位图至少 300 dpi，字体和线宽清晰
- [ ] 区间、阴影、注释和坐标范围与数据一致
- [ ] 表格无截断、贴边和溢出
- [ ] 正文对保留图表进行了深入分析

## 文档与交付

- [ ] 最终文档已渲染并逐页检查
- [ ] 页数、公式、图表和交叉引用正常
- [ ] 交付目录只包含必要文件
- [ ] 哈希仅用于关键原始数据和最终交付物
- [ ] 未执行的测试和剩余风险已明确说明
