# 图表与表格规范

## 1. 文件和语言

- 图表文件使用简洁的中文名称；
- Excel 文件名、工作表名和字段标题使用中文；
- 字段标题包含必要单位，如“温度（摄氏度）”或“预测收率（%）”；
- 专业符号和通用缩写可以保留英文，说明性文字以中文为主。

## 2. 论文用图

论文已有专业图题时，图片内部不重复放置总标题。独立展示图如确需标题，应简洁凝练，过长时合理换行，不能形成两行以上的冗长说明。

位图按最终排版尺寸导出至少 300 dpi；线图、公式图和流程图优先使用清晰的矢量格式，但不为中间检查额外生成整篇 PDF。导出后检查实际像素、字体大小和线宽，而不是只检查保存参数。

时间相关模型在有助于检查空间关系、临界时刻或协同时序时，应另行生成动态图作为支撑材料。论文中不直接依赖动画，需从动画或连续仿真中选取具有数学含义的四个典型时刻，按 `2 x 2` 统一排版。详见 [动态图与典型时刻图规范](动态图与典型时刻图规范.md)。

## 3. 统一视觉系统

同一论文中的字体、字号、颜色、线宽、点型、图例、坐标轴和小数位保持一致。图内标题如保留则统一加粗；多部分图的垂直间距采用约 10 px 或相同比例，并在最终分辨率下复核。

不要拼接风格明显不同的单图。可参考优秀论文或学术绘图规范，但必须让配色、字号和注释服从整篇论文，而不是只追求单图美观。

图表类型可以多样，但多样化不等于数量越多越好。先在 `图表规划表.csv` 中为每张图写明它支持的结论、所用数据和正文位置，再从 [图表选择目录](图表选择目录.md) 中选择合适类型。不得为了覆盖目录而机械制图。

## 4. 数据范围和注释

- 坐标轴范围应覆盖实际数据与合理外推区间，不无意义留白；
- 置信区间、误差带、可行域和高亮色块只覆盖其真实定义范围；
- 注释避开曲线、误差带、数据点和图例，并与被解释对象位置一致；
- 中英文混排只在符号、单位或通用缩写确有需要时使用；
- 颜色、阴影和渐变必须有数据含义，不能制造不存在的区间或范围。

## 5. 正文分析

图表是证据，不是装饰。正文按“引出图表—呈现图表—紧随分析”组织。每张核心图至少分析一个主要规律，并根据需要补充组间差异、异常、峰谷、拐点、不确定性及对后续模型的意义。多张图应尽量逐张分析，避免只将图例或横纵坐标重新叙述一遍。

## 6. 表格

- 内容水平和垂直居中，正文型长文本可按可读性左对齐；
- 行距尽量控制为 1.25 倍，不使用会截断文字的固定行高；
- 根据内容长度设置列宽，短字段保持紧凑，长字段获得更多空间；
- 最左、最右列保留足够内边距，避免内容贴近边缘；
- 表头、单位、有效数字和缺失值标记统一；
- 结果表默认保留四位小数，正文引用时保持同一指标精度一致；
- 跨页表重复表头，并尽量避免拆开一个逻辑记录。
- LaTeX 正文表格统一使用 `\zihao{-5}`；单元格内容尽量一行完成，可在版心范围内优先加宽表格，不能以压缩到不可读来换取单行。

## 7. 导出检查

导出后检查文件是否可打开、中文是否正常、分辨率是否达标、文字是否被裁切、颜色是否可区分、表格是否溢出，以及图表编号和正文引用是否一致。

流程图和建模示意图除导出图外，还必须保留可编辑源文件并验证可打开。示意图用于解释模型对象、几何关系或算法结构，不能代替关键命题的数学证明。具体见 [流程图与建模示意图规范](流程图与建模示意图规范.md)。
