# 数据、模型与结果合理性规范

本规范用于保证每一问形成“数据可信—模型成立—结果稳定”的完整证据链。它适用于数据预处理、模型或算法选择、自定义指标与人为阈值、模型诊断、摘要和本问结论。若旧规则只要求说明处理步骤、模型名称或结果稳定性，而未要求说明理由和验证，本规范优先。

## 1. 通用证据链

论文中的每项数据处理、模型结构、算法步骤、自定义指标和人为阈值都必须回答：

1. 为什么需要；
2. 如何建立、确定或执行；
3. 如何验证其合理性。

不能把“结果合理”本身当作验证方法。所有合理性结论必须对应当前项目实际运行得到的统计量、诊断图、样本外结果、对照或敏感性结果。

## 2. 数据预处理的依据链

数据预处理开始前，先说明原始数据存在的缺失、格式不统一、时序矛盾、逻辑冲突、重复观测或质量异常，以及这些问题可能怎样改变变量关系、参数估计或最终决策。

每项处理按以下顺序记录：

1. 数据问题；
2. 对模型或结论的潜在影响；
3. 识别规则及其来源；
4. 补全、校正、保留或删除动作；
5. 受影响记录和处理前后样本量；
6. 处理合理性及其验证证据。

可以由确定公式、题设规则或同一对象的可靠记录恢复的数据才可校正。无法判断哪个字段正确的逻辑冲突记录原则上删除。不得仅因样本少、数值特殊或不利于显著性而排除记录。

正文应概括为什么必须预处理、主要处理规则及有效样本，不能只罗列操作。没有外部数据时改为说明输入、单位、范围和题设参数核验，不得虚构清洗。

## 3. 质量标准、自定义指标与人为阈值

题目阈值或人为边界原则上采用“主分析加敏感性分析”。主分析采用题目、规范或主要理论给出的标准；敏感性分析放宽或收紧边界，并比较样本量、核心参数、显著性、样本外误差和最终方案是否变化。

每个自定义指标、可靠度标准、分组边界、误差范围或判定阈值必须说明：

1. 数学定义、单位和实际含义；
2. 为什么需要；
3. 当前形式或数值的选择依据；
4. 与主模型、目标函数和最终决策的关系；
5. 改变定义或阈值后的稳定性。

依据可以来自题目要求、公开规范或文献、数据分布特征、风险成本或训练数据中的模型评价。数据驱动阈值只能在训练数据或训练折内确定，再在验证数据中评价；不得利用验证结果反向调节阈值。没有唯一依据时必须比较相邻取值，不得只报告一个看似合适的数值。

## 4. 模型选择、过渡与优势

每次引入新模型或算法前都要说明：前一种方法解决了什么、仍缺少什么、新方法如何补足以及将输出什么。不得使用“进一步建立某模型”而不解释原因。

正文至少交代：

- 数据具有哪些结构或分布特征；
- 普通方法为什么不适用或不充分；
- 当前模型如何利用这些特征建立；
- 相对候选方法具有什么可验证的优势；
- 模型输出如何回答题目。

对数变换、随机效应、非线性项、交互项、正则化和动态规划等非常规结构必须解释采用原因、参数含义和实际作用。探索性分析只用于发现候选关系；若后续使用统计模型确认关系，应明确说明探索方法没有处理的相关性、混杂、非线性或预测问题。

## 5. 模型假设检验与诊断

模型假设不能只写在论文前置章节。最终模型求解后，必须依据模型类型检查其成立条件，并区分正式假设检验与诊断图。

线性回归和线性混合效应模型至少检查：固定效应显著性，随机效应的必要性，残差是否围绕零随机分布，方差是否基本稳定，残差和随机效应是否近似正态，以及是否存在主导结论的异常对象。重复观测模型还应检查给定随机效应后是否仍存在明显的组内或时间结构。

Logistic 或其他分类模型至少检查区分能力、校准程度、多重共线性和判定阈值稳定性。优化和仿真模型至少检查约束可行性、算法终止或收敛、搜索域覆盖以及参数扰动下方案稳定性。

大样本正态性不能只依赖单个显著性检验；应将残差图、Q-Q 图等诊断证据与数值检验结合。若假设不满足，应记录采用的变量变换、稳健估计、替代结构或敏感性处理，不能先写“假设成立”再补证据。

## 6. 三类验证不得混用

- 模型选择回答“哪个候选模型更合适”，可用似然比检验、AIC、BIC和交叉验证；
- 模型诊断回答“最终模型的统计前提是否基本满足”，主要使用残差、随机效应、校准和异常影响诊断；
- 敏感性分析回答“改变数据口径、参数或阈值后结论是否稳定”。

三类证据可以共同支持模型，但不能相互替代。较高的拟合优度、较低的交叉验证误差或稳定的敏感性结果，都不能单独证明模型假设成立。

## 7. 三层合理性结论

每一问结束前分别说明：

- 数据合理性：筛选、校正和质量控制有明确来源及影响记录；
- 模型合理性：结构与数据特征匹配，主要假设得到诊断；
- 结果合理性：核心结论通过样本外验证、结构对照或敏感性分析保持稳定。

不能只写“模型具有合理性”。结论必须指出具体证据及其支持的对象。

## 8. 论文表达

避免“为落实题目要求”“将题目点名的变量纳入模型”“下面报告结果”等过程性套话。使用数据特征、建模困难和方法作用建立因果过渡。

摘要每问按“建模对象与关键困难—模型或算法如何建立、为何选用及其优势—关键结果—合理性证据”组织。摘要不展开完整公式，但应保留核心变量处理、模型结构和求解方法。摘要中的模型算法和核心结论可突出显示；加粗区域总数原则上不超过 4 处。

全文结尾的不足与改进方向集中写 3 至 4 行，按照“当前模型解决了什么—尚未纳入什么结构—未来如何改进”组织，不在各问正文中反复加入防御性表述。

## 9. 单问执行顺序

每一问依次完成：数据基础与建模难点；探索性分析；方法选择和逻辑过渡；模型假设与变量定义；模型建立和参数解释；模型选择与求解；模型假设检验与诊断；敏感性或稳健性分析；结果解释与直接结论。

篇幅有限时可以压缩诊断展示，但不得把模型诊断完全省略或以交叉验证、敏感性分析替代。
