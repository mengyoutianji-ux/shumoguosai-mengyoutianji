# 动态图与典型时刻图规范

## 1. 何时制作

运动、扩散、覆盖、队列、迭代、参数扫描或多主体协同随时间发生重要变化时，可制作动态图作为支撑材料。若静态轨迹图已经完整回答问题，不为“形式丰富”额外制作动画。

## 2. 动态图必须稳定

- 坐标范围、视角、比例、颜色映射和图例在所有帧中保持一致；
- 每帧显示真实时刻、参数或迭代编号，不展示随机种子；
- 动态对象与静态参照物含义明确，不能因自动缩放产生虚假位移；
- 帧率只影响观看，不改变数值时间步长；
- 生成脚本、输入数据和导出格式保存在项目中；
- 输出优先使用浏览兼容的 MP4 或 GIF，并另存关键帧静态图供论文使用。

## 3. `2 x 2` 典型时刻选择

四个时刻按数学意义选取，不按画面好看选择。常用组合为：

1. 起始或事件发生前：给出初始相对位置；
2. 临界进入：判据首次成立或进入可行域；
3. 关键状态：最大响应、最近距离、协同交接或最不利时刻；
4. 临界退出或结束：判据最后成立或过程结束。

若模型没有进入与退出，应改用与题目匹配的四个节点，并在 `图表规划表.csv` 记录选择依据。四幅图使用相同视角、坐标范围、色义和对象尺度，分别标注 `(a)` 至 `(d)`、时刻和事件名称，共用一个图例。

## 4. 论文中的使用

正文先说明为什么选择这四个时刻，再放四联图，随后逐幅解释状态变化及其与公式判据的对应关系。动画作为支撑材料，不能成为读者理解结论的唯一入口。四联图若不能增加对临界过程或机制的理解，则不进入正文。

## 5. 验收

- 动画非空且确实随时间变化；
- 四幅静态图均来自同一模型运行或可核验的确定性重算；
- 时间戳、坐标和图中状态与代码结果一致；
- 四联图在最终论文尺寸下文字可读、无重叠、无遮挡；
- 正文完成“引出—呈现—逐幅分析”；
- 动画、关键帧、结果表和正文中的临界时刻一致。
