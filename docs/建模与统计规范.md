# 建模与统计规范

## 1. 从问题而不是模型出发

每一问先建立一张“目标卡”：题目原文要求、研究对象、自变量、因变量、约束、评价指标、需要回答的关系或决策，以及可接受的验证证据。题目存在多种解释时，列出每种解释对变量、约束和答案的影响；只有不影响结论的解释差异才可自行择优。会改变模型的问题先让用户选择，并把选定解释写入建模记录。

## 2. 数据预处理必须可追溯

至少核验以下内容：

- 实际样本量、变量名称、类型、单位和取值范围；
- 缺失、重复、异常、越界和编码问题；
- 删除、插补、标准化、对数或 logit 变换的理由；
- 派生变量的公式、单位和分母定义；
- 排除的样本、组合或时间段及其影响。

每项处理必须形成“数据问题—对模型或结论的潜在影响—识别规则及来源—处理动作—受影响记录和样本量变化—合理性验证”的依据链。可以由确定公式、题设规则或同一对象的可靠记录恢复的数据才可校正；无法判断正确字段的逻辑冲突记录原则上删除。不得仅因样本少、数值特殊或不利于显著性而排除记录。

涉及质量标准或筛选边界时，先呈现数据分布，再以题目或主要规范阈值作为主分析，并通过放宽或收紧阈值进行敏感性分析。比较样本量、核心参数、显著性、样本外误差和最终决策，不能只说明“阈值附近记录较少”。

正文每问第一段应在 3 至 4 行内概括为什么需要处理、实际处理规则和有效样本。若题目没有数据附件，则记录题设参数、单位、坐标系、时间基准和输入范围核验；若检查后无需修正，应写“经核验未发现……”，不能编造清洗步骤。

## 3. 变量关系的规范结论

仅写“随温度升高而上升”属于趋势描述，不是完整的统计结论。关系分析通常需要回答：

1. 方向：正相关、负相关或未发现显著相关；
2. 强弱：根据已声明阈值判断强、中等或弱关系；
3. 证据：相关系数、置信区间、显著性或重采样结果；
4. 结构：线性、非线性、分段、峰值、谷值或平台；
5. 范围：结论对应的样本、组别和自变量区间。

连续且近似线性的变量可考虑 Pearson 相关；存在异常值、等级信息或单调非线性时可考虑 Spearman 相关。不得为了得到显著结果而事后反复更换指标。非单调关系应描述曲线结构，不强行压缩为一个相关系数。

多组合结果采用“总体规律—数量证据—例外组合—例外结构”的顺序。例如：先说明多数总体正相关，再写严格单调、存在波动和非单调组合的数量，最后解释峰值或谷值。

## 4. 候选模型与简约原则

先建立具有领域意义的简单基线，再增加必要复杂度：

- 多项式拟合优先检查二次和三次；
- 参数数量必须与有效样本量相匹配；
- 小众模型必须说明其机制、参数含义和相对基线的收益；
- 同一响应不应无目的堆叠大量函数族；
- 复杂模型若未改善样本外误差、稳定性或物理合理性，应退回简单模型。

候选模型使用相同的数据范围、预处理、交叉验证划分和评价指标比较。训练集拟合优度不能代替泛化能力。

每次引入新模型或算法前都要说明：前一方法解决了什么、仍缺少什么、新方法如何补足以及将输出什么。正文至少说明模型如何建立、为何适合当前数据、相对候选方法具有什么可验证优势，以及输出如何回答题目。不得使用“进一步建立某模型”而不解释原因。

对数变换、随机效应、非线性项、交互项、正则化和动态规划等结构必须解释采用原因、参数含义和实际作用。探索性分析只用于发现候选关系；若后续使用统计模型确认关系，应明确说明探索方法没有处理的相关性、混杂、非线性或预测问题。

## 5. 评价指标、自定义指标与人为阈值

按问题选择少量主指标和必要辅助指标：

- 回归：RMSE、MAE、决定系数、调整决定系数、AICc、残差诊断；
- 分类：精确率、召回率、F1、ROC-AUC、校准误差；
- 聚类：轮廓系数、稳定性、领域可解释性；
- 优化：目标值、约束满足、收敛、扰动稳定性；
- 时间或空间问题：按时间、地点或群组切分验证，避免随机切分泄漏。

数据不平衡、分组重复测量或小样本问题应使用与数据结构匹配的验证方案。报告评价指标的定义和尺度，不能直接比较用途不同的指标；如确需对比，应先转换为共同判据。

每个自定义指标、可靠度标准、分组边界、误差范围或判定阈值都要说明数学定义、单位、实际含义、选择依据、与主模型或最终决策的关系以及改变取值后的稳定性。依据可以来自题目要求、公开规范或文献、数据分布特征、风险成本或训练数据中的模型评价。

数据驱动阈值只能在训练数据或每个训练折内确定，再在验证数据中评价；不得利用验证结果反向调节阈值。没有唯一依据时比较相邻取值并报告方案是否变化，不得只给出一个看似合适的数值。

## 6. 近完美拟合专项复核

当决定系数接近或达到 1、训练误差接近 0，或结果明显优于常识时，依次检查：

1. 因变量是否直接或间接进入自变量；
2. 训练集和验证集是否存在重复记录或同组泄漏；
3. 参数数量是否接近样本量；
4. 是否在全体数据上完成了标准化、特征选择或插补后再交叉验证；
5. 代码是否错误复用了观测值、索引或目标列；
6. 留一、留组或独立验证误差是否仍然合理；
7. 残差图、预测—观测图和边界预测是否正常。

复核结果必须写入项目记录。只有训练集上的近完美拟合不能作为模型可靠的证据。

## 7. 优化与仿真

优化模型需写清决策变量、目标函数、约束、搜索域、离散水平、求解器、步长或终止条件。正文优先用带大括号的统一形式给出目标与约束，再逐条解释。固定随机种子只用于复现，不代表结果稳定；种子值保留在代码和项目记录中，不在论文或图表中展示。稳定性应通过多次运行、扰动、参数变化或情景分析检验。

使用“模型推荐方案”表述预测结果。只有在搜索域、约束和求解精度都明确时，才表述为该范围内的最优解；不能将模型预测写成已完成实验。

## 8. 正向验证证据链

模型验证应回答“为什么可信”，而不是罗列模型局限。优先使用：

- 样本外或留组预测表现；
- 残差无系统性结构且边界合理；
- 影响方向与控制变量分析、领域机制或原始曲线一致；
- 参数、输入或随机扰动下结论稳定；
- 不同合理模型结构得到一致的主要结论；
- 推荐方案与已知实测点或约束相互印证。

必要的适用边界可以简明说明，但不能用“无法比较”“不宜解释”等防御性句子替代验证。

每一问分别给出数据合理性、模型合理性和结果合理性的具体证据。数据合理性对应筛选、校正和质量控制；模型合理性对应结构选择、假设检验与诊断；结果合理性对应样本外验证、结构对照或敏感性分析。不能用一句“模型具有合理性”概括三者。

## 9. 模型假设检验与诊断

模型选择、模型诊断和敏感性分析不得混用：模型选择比较候选结构；模型诊断检查最终模型的统计前提；敏感性分析检查数据口径、参数或阈值变化是否改变结论。

线性回归和线性混合效应模型至少检查固定效应显著性、随机效应必要性、残差零均值结构、方差稳定性、残差和随机效应正态性及异常对象影响。重复观测模型还应检查给定随机效应后是否仍存在明显组内或时间结构。大样本正态性不能只依赖一个显著性检验，应结合残差图和 Q-Q 图。

Logistic 或其他分类模型至少检查区分能力、校准程度、多重共线性和判定阈值稳定性。优化与仿真模型至少检查约束可行性、算法终止或收敛、搜索域覆盖和扰动稳定性。若假设不满足，记录变量变换、稳健估计、替代结构或敏感性处理，不能先写“假设成立”再补证据。

## 10. 公式解释与关键证明

模型的每一部分应按“建模对象—公式—符号与关系—作用”展开。决定最终答案是否成立的条件必须形成证明或严格论证，包括几何覆盖、可行域边界、等价变换、极值存在性、算法终止或离散化充分性等。详细记录格式和检查要求见 [建模表达与关键证明规范](建模表达与关键证明规范.md)。

数据、模型、阈值和合理性论证的完整要求见 [数据、模型与结果合理性规范](数据模型与结果合理性规范.md)。
