# 优秀论文参考使用规范

## 1. 参考目的

优秀论文用于学习可验证的表达方式，包括公式如何引出、模型如何分层、关键证明放在何处、图表如何承接正文、优化模型如何排版以及结论如何直接回答问题。不得只模仿配色、术语密度或版式外观。

## 2. 阅读记录

使用 `参考论文写作特征记录.md`，逐篇记录：

- 来源、年份、题号和可核验的获奖或公开状态；
- 值得借鉴的具体段落结构或图表功能；
- 该写法解决了什么表达问题；
- 能否迁移到当前题目，需做哪些改写；
- 不应照搬的内容和原因。

至少比较两篇后再确定论文风格，避免把单篇论文的个性化写法误当作普遍规范。

## 3. 引用与版权边界

- 优先使用竞赛官网或官网直接链接的公开材料；
- 官方页面只有图片时，不把第三方 OCR 或网盘文件描述为“官方 PDF”；
- 未确认再分发许可时，不把论文全文、截图或裁剪图复制到公开工作流仓库；
- 需要在具体项目中内部参考时，把文件放在项目材料区并在材料清单中记录来源、用途和公开边界；
- 论文文字、图件和公式说明必须针对当前题目重新建立，不能替换名称后照搬。
