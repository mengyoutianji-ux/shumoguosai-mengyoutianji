# 图表选择目录

本目录用于从“论文要证明什么”反推图表类型，不是要求把所有图都画出来。每张候选图先写入 `图表规划表.csv`，明确所支持的论断、数据来源、正文位置和验证用途，再决定是否进入论文。

## 1. 选择顺序

1. 明确需要展示的是趋势、比较、分布、关系、不确定性、参数响应、时序、空间结构还是算法过程；
2. 先选能直接回答该问题的二维图，再判断三维或动态形式是否带来额外信息；
3. 同一论断只保留信息增益最高的一至两张图，避免热力图、曲面图和等高线图重复表达同一结果；
4. 结果图与验证图分开规划；迭代、收敛、敏感性和鲁棒性不能只用文字代替；
5. 所有保留图都完成正文“引出—呈现—分析”闭环。

## 4. 常见误用

- 饼图、雷达图和三维柱状图只在数据结构确实匹配时使用，不能因为形式新颖而替代更清楚的条形图或散点图；
- 3D 曲面、等高线和热力图若表达同一响应面，正文通常保留一至两种即可；
- 动画和交互式图必须提供静态替代，保证论文和离线交付仍能独立阅读；
- 箱线图、小提琴图和雨云图不能同时堆叠表达同一组分布，除非分别承担不同验证任务；
- 迭代曲线需同时标注目标变化和终止依据，不能只展示“曲线趋稳”；
- 图表目录不能替代领域判断、关键证明或结果分析。
